# Hanyu HTML Deck（本地演示台）

[中文](README.md) · [English](README.en.md)

面向 AI 生成 HTML 演示文稿的本地优先框架。

本地演示台同时提供一个可直接复制的演示模板和一个独立 skill。核心 HTML 不需要安装、账号或网络；双击文件即可演示。开启本地服务后，可使用手机提词器、遥控、源文件写回和导出。

## 它是什么，不是什么

本地演示台提供的是演示能力与制作流程：翻页、分步动画、讲稿、备注、手机提词、源文件写回和导出。

它不是一套幻灯片视觉模板，不提供主题皮肤、配色方案或成套版式。仓库里的 `template.html` 是一个可运行的起点，其中的示例页只是页面骨架；真正的版面由 AI 按每份内容重新组织。如果需要的是现成好看的版式套件，这个项目不解决这个问题。

## 适合什么情况

- 使用 Codex、Claude Code 等 AI 编程工具制作 HTML 演示文稿。
- 希望把页面、讲稿和修改备注放在同一个文件中。
- 正式演示时需要手机提词和遥控，但不希望依赖公网服务。
- 需要从浏览器把文字修改安全地写回原始 HTML。

## 功能边界

| 功能 | 只打开 HTML | 需要本地服务 |
|---|:---:|:---:|
| 浏览、翻页、总览、演示模式 | ✓ | ✓ |
| 页面内分步动画与悬停交互 | ✓ | ✓ |
| 编辑讲稿与备注并保存在浏览器 | ✓ | ✓ |
| 记住讲稿面板和备注抽屉状态 | ✓ | ✓ |
| 导出讲稿、复制改动的备注 | ✓ | ✓ |
| 手机提词器与手机遥控 | | ✓ |
| 把讲稿、备注和画布文字写回源文件 | | ✓ |
| 导出每页图片、导出 PDF、导出单独发送版 | | ✓ |

本地服务只在当前局域网内工作，不连接公共中继，不上传讲稿。手机与电脑不在同一网络的情况不在本项目范围内。

## 快速开始

```bash
git clone <仓库地址>
cd hanyu-html-deck
python3 scripts/create_deck.py ~/Documents/my-deck
```

然后：

1. 打开 `my-deck/index.html`。
2. 修改文件尾部的 `DECK.name` 与 `DECK.key`。
3. 用模板里的页面骨架替换示例内容。
4. 需要高级功能时，双击 `启动本地演示台.command`。

核心 HTML 可在 macOS、Windows 和 Linux 的现代浏览器中使用。0.1 版的本地服务、启动文件与导出流程只在 macOS 上验证过：图片、PDF 与发送版导出依赖 macOS 自带的 `sips`，在 Windows 与 Linux 上不可用；这些系统上可用 `python3 scripts/prompter_server.py` 启动服务使用手机提词与写回。

## 安装 Skill

Skill 让 AI 编程工具直接按本项目的约定生成演示稿。两种用法：

- 装成常驻 skill：把仓库里的 `SKILL.md` 连同仓库一起放到 AI 工具读取 skill 的目录（例如 `~/.claude/skills/hanyu-html-deck/`），并在其中保留 `assets/` 与 `scripts/`，Skill 里的相对路径才成立。
- 不安装也能用：让 AI 读取仓库里的 `SKILL.md`，再说明目标目录即可。

调用时给出内容、场合与页数，并明确要求使用本地演示台 Skill。

## 讲稿与备注

底部区域默认只显示一行表头。按 `N` 或点击中间把手可展开讲稿。讲稿使用自然段纯文本，不要求目的、主次或项目列表。

展开后，讲稿栏右下角有一个侧栏图标，点击后备注抽屉从右侧推入。备注可用于修改意见、补充说明或个人提醒。关闭抽屉只切换视图，内容不会删除。

讲稿面板是否展开、备注抽屉是否打开会分别写入 localStorage，并按 `DECK.key` 隔离。

导出菜单中：

- `导出讲稿`：下载包含全部页面讲稿的 Markdown 文件。
- `复制改动的备注`：只复制用户改过的备注，按页分组，便于粘贴给 AI。
- `导出每页图片`：逐页截图成 PNG，需要本地服务与 Playwright。
- `导出 PDF`：先逐页截图再合成 PDF，版面与动效终态一致。
- `导出单独发送版`：单文件 HTML，内联字体与图片，剥除备注和写回代码。
- `切换为 1:1 像素`：关闭画布缩放，供 Figma 插件或 DOM 抓取工具读取 1920 × 1080 的真实坐标。

菜单里每一项悬停约一秒会显示一句说明。

## 手机提词器

先双击 `启动本地演示台.command`，再点击演示稿右上角的手机图标。界面会显示当前局域网地址和二维码。网络发生变化后，二维码会自动刷新。

推荐连接顺序：

1. 手机和电脑连接同一个可信 Wi-Fi。
2. 没有可用 Wi-Fi 时，开启手机热点，并让电脑连接这个热点。

手机端默认显示讲稿；点击顶部 `讲稿 / 备注` 可切换。两栏分别保留每一页的滚动位置。手机可跟随电脑翻页，也可切换成自由浏览。

正式演示前 5–10 分钟：

1. 扫码打开提词器。
2. 用手机前后翻两页，确认电脑同步。
3. 关闭手机和电脑的 VPN 或代理。
4. 避免自动锁屏，并让手机保持供电。

## 本地服务与依赖

手机提词、遥控和源文件写回只需要 Python 3，QR 生成器已经随项目提供。

图片和 PDF 导出还需要：

```bash
python3 -m pip install playwright
python3 -m playwright install chromium
```

发送版 HTML 不需要 Playwright。发送版会内联字体和图片，并剥除备注与浏览器写回代码。

## 浏览器写回

- 讲稿与备注的改动在输入停顿约 1.5 秒后自动写回 `index.html`，不需要点保存。
- 讲稿栏右下角有一盏同步灯：绿色表示都已写回文件，橙黄表示还有改动只存在这个浏览器里（多半是本地服务没启动）。悬停即可看到原因。
- 灯旁边是历史按钮：讲稿与备注各有一条版本时间线，可回到任一历史版本或默认稿。
- 双击画布文字可直接修改，失焦后写回源文件。
- 画布写回只接受本机请求；写回前会核对页数、页面结构和危险标签，并使用临时文件原子替换。

## 键盘

- `← / →`：上一页 / 下一步或下一页
- `P` 或 `F`：演示模式
- `O`：总览
- `N`：展开或收起讲稿
- `R`：切换为 1:1 像素
- `Esc`：退出当前模式

## 仓库里有哪些文件

`scripts/create_deck.py` 会把普通用户真正需要的模板、字体、本地服务和说明复制到新项目中。源码仓库还保留以下开发文件，它们不会进入生成出的 Deck：

- `tests/`：检查页面与讲稿一一对应、状态分开保存、局域网边界和产品文案，避免后续修改破坏已有功能。
- `evals/`：检查 AI 是否能按 Skill 的约束生成合格的 Deck。
- `.github/workflows/ci.yml`：每次提交后自动运行测试。
