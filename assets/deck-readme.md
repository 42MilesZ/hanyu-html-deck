# 本地演示台演示稿

双击 `启动本地演示台.command`：它会启动本地服务并打开演示稿，此时手机提词器、手机遥控、自动写回、每页图片、PDF 和发送版导出都可用。

只想离线看一眼时，直接双击 `index.html` 也能浏览、演示、编辑讲稿与备注——改动实时存在浏览器里，但不会写回文件。

写回凭据由服务在启动时写进 `index.html`，所以页面要在服务启动之后打开。如果页面先开着、服务后启动，刷新一下页面就好。

里面的示例页只是页面骨架的起点，不是要照搬的视觉方案；替换成自己的内容时，版面按内容重新组织即可。

翻页可以用 `← / →`，也可以点击画面左右边缘，鼠标移上去会出现箭头提示。

展开讲稿后看右下角那盏灯：绿色表示改动已写回 `index.html`，橙黄表示还只在浏览器里。悬停会展开浮层，告诉你是哪几页、以及该怎么办。

手机与电脑优先连接同一个 Wi-Fi。没有合适网络时，开启手机热点并让电脑连接。正式演示前 5–10 分钟完成一次预演：扫描二维码、前后翻两页、关闭 VPN，并让手机保持供电。
